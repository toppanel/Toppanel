# Products Image Upload Checklist

Use this checklist when preparing images for the products section.

## Before upload

- [ ] Confirm the product category
- [ ] Choose the correct folder
- [ ] Rename the file using the recommended pattern
- [ ] Check image resolution and aspect ratio
- [ ] Optimize the image for web

## Recommended folder by category

- Cubicle → /images/products/cubicle/
- Accessible → /images/products/accessible/
- Glass → /images/products/glass/
- Changing room → /images/products/changing-room/
- Lower cabinet → /images/products/lower-cabinet/
- Wall panel → /images/products/wall-panel/

## Recommended file names

- cubicle-stainless-01.jpg
- cubicle-kids-01.jpg
- accessible-sliding-01.jpg
- glass-partition-01.jpg
- changing-room-01.jpg
- lower-cabinet-01.jpg
- wall-panel-01.jpg

## After upload

- [ ] Confirm the path is correct
- [ ] Update the product data if necessary
- [ ] Preview the image in the products page
- [ ] Check that the image appears in the gallery and popup
