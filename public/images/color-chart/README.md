# Color chart images

Drop the two color chart images here, named exactly:

- `color-chart-01.jpg`
- `color-chart-02.jpg`

(`.png` also works — just update the filename in
`src/components/home/ColorChartPreview.tsx` to match if you use a
different extension.)

They render full-bleed (edge to edge, no cropping) stacked on the
homepage — whatever width/height you upload is what visitors see, so
export them at the resolution you want displayed at.
