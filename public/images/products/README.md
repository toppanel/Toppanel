# Products images

Store product-related images here, one folder per product category.

Categories with many model types (like `cubicle`) go one level deeper —
one subfolder per model slug — so each type stays browsable even once it
holds thousands of photos:

- cubicle/stainless/cubicle-stainless-01.jpg
- cubicle/kids/cubicle-kids-01.jpg
- accessible/accessible-sliding-01.jpg
